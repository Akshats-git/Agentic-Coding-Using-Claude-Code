## Vibe coding vs agentic coding
**Vibe coding** means you depend almost fully on AI. The loop has three steps.
1. You write a plain English prompt.
2. The AI generates the full code.
3. You test it, report problems, and the AI fixes them.

**Where vibe coding is fine**
- Building a minimum viable product.
- Exploring an idea.
- Hackathon projects.
- Any low stakes work.

**Where vibe coding fails**
- Scalable systems used by millions of people.
- Critical infrastructure like banking or insurance software.
- Any high stakes project.

**This playlist does not teach vibe coding.** It teaches AI assisted coding, also called agentic coding. Here you stay in control and use AI agents for specific parts of the work.

## The project of the playlist
The playlist builds one full website end to end. It is an expense tracking website.

Features of the website:
- Landing page.
- User registration and login.
- User dashboard after sign in.
- Summary stats such as total spend, number of transactions, and top spending category.
- Full transaction history with descriptions.
- Spending analysis by category.
- Date filter so you can see any time range.
- Add a new expense.
- Edit or delete an existing expense.

The project is kept simple on purpose. The goal is to learn Claude Code and not to fight with complex features.

## What else the playlist covers
- Building features with a proper AI assisted workflow.
- Creating agents and subagents.
- Running multiple agents in parallel to build features at the same time.
- Deploying the finished website to a cloud platform using Claude Code.

## Why Claude Code and not other tools
Other tools exist such as Cursor, Windsurf, OpenAI Codex, Replit, and Lovable. Claude Code was chosen for these reasons.
- Strong raw coding intelligence, especially the Opus model.
- A very long context window that handles large codebases well.
- Better at architecture design and refactoring.
- Strong agentic features for testing, code review, and parallel work.
- It feels like working with a senior software engineer.
